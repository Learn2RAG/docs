## File System
Add local (on the same PC or server where Learn2RAG is running) directories.
For example: `/home/user/Documents`, `C:\Users\User\Documents`.

## Web Pages
Add URLs of web pages.
For example: `https://en.wikipedia.org/wiki/Berlin`.
